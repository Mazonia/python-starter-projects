**Python Starter Projects Suite** is a polished, modular collection of fundamental Python algorithms, CLI utilities, and interactive web tools designed for software engineering practice, network calculations, string processing, and algorithmic problem-solving.

---

## ✨ Features & Project Catalog

| Utility / Algorithm | Description | Function Signature |
| :--- | :--- | :--- |
| 🔐 **Caesar Cipher** | Encode and decode messages using letter shifting. | `caesar_cipher(text, shift, direction)` |
| 📧 **Email Domain Replacer** | Safely update email domains across records. | `change_email_domain(email, old, new)` |
| 🌐 **VLSM IP Subnet Calculator** | Compute network ranges, broadcast addresses, and netmasks. | `calculate_subnets(network_cidr, hosts)` |
| 🔑 **Password Generator** | Generate secure, customizable random passwords. | `generate_password(length, use_digits, use_symbols)` |
| 🐷 **Pig Latin Translator** | Convert English sentences into Pig Latin. | `pig_latin_translate(text)` |
| 🔄 **Palindrome Checker** | Ignore non-alphanumeric characters and test symmetry. | `is_palindrome(text)` |
| 📅 **Leap Year Evaluator** | Determine leap years according to Gregorian rules. | `is_leap_year(year)` |
| 🎓 **Academic Grading System** | Map numerical test scores to letter grades. | `calculate_grade(score)` |
| 📊 **Frequency Counter** | Count element occurrences in sequences. | `count_frequency(items)` |
| 🛗 **Elevator Simulator** | Model multi-floor elevator movements and directions. | `elevator_simulate(current, targets)` |

## 🚀 Quick Start

### 1. Interactive Web Application
Open [`index.html`](index.html) in any web browser to use live JavaScript/Python-powered interactive tools.

### 2. Command-Line Demo Runner
```bash
python main.py
```

### 3. Run Automated Unit Tests
```bash
python -m unittest test_starter_projects.py
```
